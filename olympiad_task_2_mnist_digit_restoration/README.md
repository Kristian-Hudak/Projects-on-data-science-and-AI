# Olympiad Task 2: Handwritten Digit Inpainting & Elastic Corruption Restoration

**Competition:** Slovak National Olympiad in Artificial Intelligence (Olympiáda v umelej inteligencii — OAI)  
**Author:** Kristian Hudák  
**Round:** National Qualifier / Home Round

---

## Project Overview

In this computer vision competition task, participants were challenged to restore a set of 2,000 handwritten digits ($28 \times 28$) that suffered severe synthetic erasure damage. The corruption was generated by overlaying cubic Bézier curves that wiped out significant stroke continuity (mimicking an eraser tool across the canvas).

---

## Technical Solution

1. **Architecture:** A multi-stage Convolutional Denoising Autoencoder combining strided 2D convolutions, max pooling, and transposed 2D convolutions (`nn.ConvTranspose2d`) for sub-pixel image reconstruction.
2. **Transfer Learning & Fine-Tuning:**
   - Started from a baseline MNIST autoencoder checkpoint (`pytorch_mnist_autoencoder_model.pth`).
   - Fine-tuned the network using paired training examples generated on the fly via a custom PyTorch dataset (`RepairDataset`).
3. **Loss & Convergence:** Optimized using Mean Squared Error (`MSELoss`) and Adam optimizer, compelling the network to learn smooth continuity priors for handwritten digit strokes.
4. **Deliverables:**
   - `mnist_digit_restoration_autoencoder.ipynb`: Full end-to-end training and inference notebook.
   - `repairer.pth`: Fine-tuned PyTorch state dictionary checkpoint.
   - `2000_fixed_digits.pt`: The final restored competition evaluation tensor dataset.
